## 1. 场景概述

本项目构建了一个以第三视角自由拖拽、旋转、平移、缩放观察的**三渲二英伦雨夜街角咖啡店微缩三维模型（Miniature Diorama）**，全程无任何 UI 界面干扰，所有建筑与街头要素均紧凑搭建在带胡桃木包边、黄铜铭牌与地下砖拱排水剖面的完整正方形底座之上。

## 2. 核心特征与要素清单

### 2.1 三渲二美术与渲染管线 (`src/materials.js`, `src/main.js`)
- **双层卡通轮廓线**：结合背面壳体扩张（Back-face Inverted Hull）与 `EdgesGeometry` 建筑结构墨线，配合后期屏幕空间 Sobel 边缘强化（`AnimeFinishingShader`）与 `UnrealBloomPass` 暖色辉光。
- **13 种程序化二次元手绘贴图**：伦敦红砖立面、湿润约克石板、鹅卵石小巷、沥青路面与英式道路标线、墨绿描金复古店招、手绘粉笔菜单黑板、维多利亚几何拼花地砖、人字拼橡木地板、彩绘玻璃横窗（Stained Glass Transom）、条纹遮阳雨棚、咖啡豆麻袋等。
- **实时雨夜路面镜面反射**：基于 `Reflector` 平面反射叠加半透明湿润沥青与积水层，真实倒映暖黄橱窗、复古路灯、红黄绿信号灯与双层巴士/出租车车灯。

### 2.2 伦敦街角咖啡店建筑与小巷 (`src/cafeBuilding.js`)
- **英伦店面门头**：经典英国赛车绿（British Racing Green）与深胡桃木立柱门头、复古金字招牌 `THE BLOOMSBURY KETTLE` 与 `BLOOMSBURY ROASTERS`、天鹅颈黄铜招牌灯、街角铁艺悬挂茶壶徽标招牌。
- **高透大面积玻璃橱窗与 45° 街角窄门**：南向与东向大面积清透橱窗、顶部发光彩绘玻璃横窗、45° 内凹街角精窄门框、微敞木门、门口迎宾垫与悬挂玻璃黄铜风铃。
- **红砖立面与屋顶**：二层英式红砖墙体、波特兰石隅石（Quoins）与檐口、维多利亚六格上下推拉窗（Sash Windows，内置暖色窗帘透光与窗台花箱）、铜质雨落水管、威尔士石板孟莎屋顶（Mansard Roof）与陶土烟囱管。
- **鹅卵石小巷入口**：西侧红砖拱门、铁艺格栅、暖光小巷壁灯、攀爬常春藤与堆叠木箱。

### 2.3 咖啡店室内高细节陈设 (`src/cafeInterior.js`)
- **地面**：前区维多利亚黑白几何拼花砖（黄铜压条收口）过渡至窗边暖色人字拼木地板。
- **吧台与设备**：L 型胡桃木与大理石台面吧台、双头意式浓缩咖啡机与双磨豆机、内部照明玻璃甜点展示柜（分层陈列草莓奶油蛋糕、维多利亚海绵蛋糕与金黄可颂）、复古黄铜收银机、按压铃。
- **后吧与陈列**：三联黑板菜单（`ESPRESSO BAR` / `LONDON TEAS` / `FRESH BAKERY`）、双层实木杯架与多色陶瓷马克杯、三层法棍与欧包陈列架、印字咖啡豆麻袋（`COLOMBIA` / `ETHIOPIA` / `KENYA AA`）。
- **客座与装饰**：6 组靠窗圆桌与曲木椅（配发光黄铜小台灯、冒热气的拉花咖啡杯、可颂餐盘与摊开书籍）、高大红木书架、装裱伦敦风景画与植物学海报、角落龟背竹绿植、复古吊灯与暖色壁灯、带发光圆舷窗的后厨门。

### 2.4 伦敦街头景观要素 (`src/streetProps.js`, `src/baseAndStreet.js`)
- **街道与交通设施**：约克石板人行道、花岗岩路缘石、铸铁下水道排水篦子与雨水沟、反光斑马线与双侧闪烁黄球灯柱（Belisha Beacons）、英式双黄线与路边虚线停车位、街角行人护栏与铸铁防撞柱、英式白边三色交通信号灯。
- **街头小品与英伦车辆**：门口 A 字小黑板菜单、绣球花与英伦玫瑰花箱、雨棚下户外小圆桌与折叠椅、金尖铁艺栏杆、斜靠栏杆的复古辐条自行车（带车篮与挡泥板）、英国皇家邮政红色圆柱邮筒（Royal Mail Pillar Box）、黑金铸铁垃圾桶、湿润木条长椅、3 座维多利亚铸铁复古路灯（配西敏市风格街道路牌 `BLOOMSBURY WAY WC1` / `CHARING CROSS RD`）、路边亮灯的伦敦黑色出租车（Black Cab）与外侧车道驶过的红色双层巴士（Routemaster）。

### 2.5 11 项实时生命力动效 (`src/effects.js`)
1. **持续降雨**：1,500 道微倾斜二次元雨丝在底座空间内持续飘落（自动避开室内空间）。
2. **屋檐滴水**：水珠在条纹雨棚波浪前檐凝结并加速滴落至地面。
3. **玻璃窗雨滴滑落**：折射室内暖光的雨滴沿南、东两侧大橱窗玻璃蜿蜒滑落。
4. **地面积水波纹**：70 组同心圆水波纹在路面水洼、人行道与小巷内持续扩散消隐。
5. **石砖路面水流**：排水沟与鹅卵石小巷表面的流光水痕顺坡流向铸铁雨水篦子。
6. **咖啡机与咖啡杯微弱蒸汽**：意式咖啡机顶部及靠窗桌面咖啡杯上方缓缓升腾旋转的半透明白雾。
7. **门口风铃、木门与悬挂招牌微晃**：随微风轻柔摆动。
8. **招牌与橱窗灯光轻微闪烁**：天鹅颈招牌灯与室内吊灯呈现柔和暖光呼吸与偶发灯丝微闪。
9. **路面积水实时反射**：动态车灯、信号灯与暖黄橱窗在潮湿路面上实时倒映。
10. **交通信号灯循环变化**：遵循英国交通灯时序（红 → 红+黄 → 绿 → 黄 → 红）切换并投射对应地面反光，斑马线黄球灯同步呼吸闪烁。
11. **远处车辆灯光朦胧掠过**：暖色车头灯与红色尾灯在湿润沥青路面上柔和掠过。

## 3. 运行方式

- **免服务直接打开**：直接双击 [`index.html`](index.html) 或 [`index.htm`](index.htm) 即可在浏览器中直接运行（已通过 `build.js` 预打包离线 [`bundle.js`](bundle.js)，无 `file://` 跨域限制）。
- **本地开发服务**：
  ```bash
  npm install
  npm start
  ```
  浏览器访问 `http://localhost:8080/`。
