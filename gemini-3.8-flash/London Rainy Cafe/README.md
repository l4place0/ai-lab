## 1. 场景概述

本项目以第三视角自由拖拽、旋转、缩放观察的微缩三维模型（Miniature Diorama）形式，搭建了一处典型的伦敦雨夜街角咖啡店微缩景观。场景无任何 UI 界面元素干扰，所有元素均搭建在一个完整的正方形底座上。画面采用三渲二（Toon Shading / NPR）风格，强调英伦街景与二次元日常治愈氛围，展现室外潮湿微冷的雨夜与室内温暖明亮灯光的鲜明对比。

## 2. 核心特征与要素清单

### 2.1 三渲二美术风格与渲染管线
- **阶梯光阶与轮廓线**：使用带自定义四阶梯度贴图的 `MeshToonMaterial` 与反向法线外壳轮廓线（Inverted Hull Outline），呈现干净明确的二次元动画线条与柔和明暗分界。
- **10 组程序化二次元手绘贴图**：纯 Canvas 程序化生成高分辨率纹理，包含伦敦红砖墙面、湿润约克石板人行道、带斑马线与黄线的雨夜沥青、墨绿烫金店招（`THE MONOCLE & BEAN`）、手绘手写粉笔菜单黑板、人字拼橡木地板、麻袋标签、复古旅行海报与积水波纹法线贴图。
- **高对比冷暖光影**：室外采用普鲁士蓝与暗石板灰冷调雨夜天光（0x0c1017 / 0x425875），配合室内 2800K 暖黄灯光与维多利亚路灯暖晕，形成鲜明温差感。

### 2.2 咖啡店建筑外观
- **英伦门头与招牌**：经典英伦赛车绿（British Racing Green）木质雕花立柱与门头，搭配复古烫金英文字招牌 `THE MONOCLE & BEAN - EST. 1892` 与顶部门线。
- **全景落地大玻璃窗**：大面积清透玻璃橱窗与转角采光窗，深色木质窗框与横竖细分线条，让室内明亮陈设一览无余。
- **红砖立面与经典推拉窗**：上层为两层维多利亚红砖墙体，配有白色上下双挂推拉窗（Sash Windows，透出暖色窗帘与室内微光）、石膏檐口雕花及顶部陶土烟囱管与紫铜落水管。
- **条纹雨棚**：墨绿与米白相间的帆布斜面雨棚，带有金属支撑臂架与波浪花边下垂门帘。

### 2.3 咖啡店室内高细节陈设
- **木质吧台与设备**：L 型深色红木吧台配黄铜封边与脚踏杆；台面上置有双冲煮头电镀铬与黄铜意式浓缩咖啡机（带蒸汽喷杆与压力表盘）、咖啡杯保温架。
- **点心展柜与收银区**：三层透明玻璃甜点柜内陈列金黄牛角可颂、巧克力切片蛋糕与浆果水果挞；复古黄铜按键收银机与透明小费罐、外带纸杯组。
- **货架与陈列**：后吧多层实木置物架，整齐摆放多色陶瓷马克杯、烘焙咖啡豆玻璃罐、粗麻布咖啡生豆袋（印字 `100% ARABICA ETHIOPIA YIRGACHEFFE`）、风味糖浆压泵瓶与精装书列。
- **靠窗小座与客区**：靠窗木质吧台桌配高脚皮垫吧椅，台面放有冒热气的拉花拿铁、咖啡碟、银匙与翻开的手绘速写本；角落设有圆形木桌、曲木椅与陶瓷花瓶；转角处摆放大型陶盆龟背竹（Monstera）。
- **室内装饰与照明**：墙上挂有伦敦复古地下铁海报与大号手写黑板菜单；天花板垂下多组暖光爱迪生钨丝吊灯，地面铺设温润的人字拼木地板。

### 2.4 伦敦街头景观要素
- **维多利亚复古路灯**：八角形铸铁基座、竖棱灯柱、检修横杆与六角形煤气灯头，散发温暖灯光并投射半透明光晕。
- **皇家邮政红色邮筒**：英国街头标志性圆柱形红色邮筒（Royal Mail Pillar Box），带有黑色基座、投信口与白色投递时间表牌。
- **街角路牌与标识**：西敏市风格白底黑框搪瓷街牌 `ST. MARTIN'S LANE WC2`；人行横道配有黑白斑马柱与脉动发光的黄色贝利沙信号球灯（Belisha Beacon）。
- **户外街头设施**：雨棚下的铁艺小圆桌与折叠椅；立式 A 字木框今日特价黑板看板；橱窗下方繁茂湿润的绿植与花箱；靠墙停靠的复古辐条自行车（带前置藤编车篮）；街沿花岗岩路缘石、铸铁防撞路桩、黑色铸铁垃圾桶与湿润木条长椅。
- **道路与远景车辆**：带反光斑马线与黄色双实线的湿滑路面、下水道雨水篦子与排水井盖；道路边缘停靠若隐若现的经典伦敦红色双层巴士（15路特拉法加广场）与穿透雨幕的漫射大灯。

### 2.5 基础动效
1. **持续降雨**：1,800 道带微倾斜夹角的半透明浅蓝雨丝粒子持续下落并在边界平滑重置。
2. **屋檐滴水**：水滴从遮阳雨棚波浪边缘间歇凝结并加速滴落至人行道。
3. **玻璃窗雨痕滑落**：沿咖啡店橱窗大玻璃表面缓慢滑动的晶莹细雨痕。
4. **地面积水波纹**：路面与人行道水洼上随机周期扩散并淡出的同心圆环形涟漪波纹。
5. **咖啡蒸汽升腾**：意式咖啡机蒸汽喷头与靠窗桌面咖啡杯上方缓缓升起飘散的半透明蒸汽粒子。
6. **门铃与风铃微晃**：店门上方黄铜小铃铛随微风细微摆动。
7. **灯光有机呼吸微闪**：维多利亚煤气路灯细微模拟气灯火苗微颤，斑马线黄色贝利沙灯球呈现周期性律动呼吸。

## 3. 运行方式

- **免服务直接打开**：双击 [`index.html`](index.html) 或 [`index.htm`](index.htm) 即可直接在现代浏览器中全屏交互浏览（已内嵌全部模型与贴图逻辑，完全免服务、零外部网络依赖）。
